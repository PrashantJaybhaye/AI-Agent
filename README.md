## 🚀 Getting Started

Get Siora up and running on your local machine in minutes.

### 📋 Prerequisites

Before you begin, ensure you have the following installed:

![Node.js](https://img.shields.io/badge/Node.js-LTS-339933?style=flat-square&logo=node.js)
![npm](https://img.shields.io/badge/npm-latest-CB3837?style=flat-square&logo=npm)
![Expo](https://img.shields.io/badge/Expo_Go-Required-000020?style=flat-square&logo=expo)

- **Node.js** (v18 or higher - LTS recommended)
- **npm** or **yarn** package manager
- **Expo Go** app on your mobile device, OR
- **Android Studio** / **Xcode** for emulators

### ⚙️ Installation

Follow these steps to set up the project:

#### 1️⃣ Clone the Repository

```bash
git clone https://github.com/PrashantJaybhaye/AI-Agent.git
cd AI-Agent
```

> **Note:** The project folder is named `siora` locally

#### 2️⃣ Install Dependencies

```bash
npm install
# or if you prefer yarn
yarn install
```

#### 3️⃣ Configure Environment Variables

Create a `.env` file in the root directory:

```bash
# Copy the example file
cp .env.example .env
```

Add your API keys and configuration:

```env
# Clerk Authentication
EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_your_key_here

# Firebase Configuration
EXPO_PUBLIC_FIREBASE_API_KEY=your_api_key
EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
EXPO_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
EXPO_PUBLIC_FIREBASE_APP_ID=your_app_id

# Optional: LiveKit & ElevenLabs (if using custom implementation)
# EXPO_PUBLIC_LIVEKIT_URL=wss://your-livekit-server.com
# EXPO_PUBLIC_ELEVENLABS_API_KEY=your_elevenlabs_key
```

> 🔑 **Getting API Keys:**
>
> - **Clerk**: [clerk.com](https://clerk.com) - Free tier available
> - **Firebase**: [firebase.google.com](https://firebase.google.com) - Free Spark plan
> - **LiveKit**: [livekit.io](https://livekit.io) - Free tier available
> - **ElevenLabs**: [elevenlabs.io](https://elevenlabs.io) - Free tier available

#### 4️⃣ Start the Development Server

```bash
npx expo start
```

#### 5️⃣ Run on Your Device

After starting the server, you have multiple options:

- **📱 iOS**: Press `i` or scan QR code with Camera app
- **🤖 Android**: Press `a` or scan QR code with Expo Go app
- **🌐 Web**: Press `w` to open in browser

## ❓ Troubleshooting

Encountering issues? Here are solutions to common problems:

### 🔧 Common Issues

<details>
<summary><b>Metro Bundler not starting or stuck?</b></summary>

**Solution:**

```bash
# Clear Metro bundler cache
npx expo start --clear

# Or reset the project
npm run reset-project
```

</details>

<details>
<summary><b>Audio/Microphone not working on Android?</b></summary>

**Solution:**

1. Ensure microphone permissions are granted in device settings
2. Check `app.json` for `android.permissions` array
3. Rebuild the app: `npm run android`

```json
"android": {
  "permissions": [
    "RECORD_AUDIO",
    "MODIFY_AUDIO_SETTINGS"
  ]
}
```

</details>

<details>
<summary><b>"Clerk: Missing Publishable Key" error?</b></summary>

**Solution:**

1. Verify `.env` file exists in the root directory
2. Check that `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY` is set correctly
3. Restart the development server: `npx expo start`
4. Ensure the key starts with `pk_test_` or `pk_live_`
</details>

<details>
<summary><b>Firebase connection errors?</b></summary>

**Solution:**
